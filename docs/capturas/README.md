# Capturas reales para la entrega del parcial

Esta carpeta está reservada para capturas **reales** de la app ejecutándose en Android.

Tomá al menos cuatro capturas de:

- Resumen del taller con datos reales de prueba.
- Detalle de una orden con responsable, trabajos y costo.
- Inventario mostrando stock bajo.
- Historial del equipo con varias visitas.

Con Android Studio: abrí el emulador, ejecutá `flutter run` y usá el botón de captura de pantalla del emulador. Guardá las capturas PNG aquí y agregalas al repositorio antes de entregar. No reemplaces esta exigencia por mockups.
